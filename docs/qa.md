# DevSnip 수동 QA

`npm run dev`로 시작하고 터미널에 표시된 localhost 주소를 엽니다.

## 키보드와 검색

1. Ctrl+K 또는 Mac의 ⌘K로 검색창에 포커스를 이동합니다.
2. React 스택에서 `useStte`를 입력해 useState가 첫 결과인지 확인합니다.
3. `use`로 검색하고 ↑ / ↓로 항목을 바꿉니다. 검색창 포커스는 유지되어야 합니다.
4. Tab으로 언어를 바꾸고 Enter로 복사합니다. 편집기에 붙여넣은 코드가 선택된 항목·언어와 같아야 합니다.
5. 연속 두 번째 Tab으로 다음 요소에 포커스가 이동하는지 확인합니다. Shift+Tab의 역방향 이동과 일반 버튼·링크의 Enter 동작도 확인합니다.
6. 목록에 포커스한 뒤 방향키로 이동하면 포커스와 선택이 함께 바뀌어야 합니다. Space로 선택 항목을 열 수 있습니다.
7. 한글 조합을 Enter로 확정할 때 코드가 복사되지 않아야 합니다.
8. `zzzzzzzzzz` 검색 후 이전 코드와 복사 버튼이 사라지는지 확인합니다.
9. 검색창에서 Escape로 검색어를 지우고, 빈 상태에서는 검색창 포커스를 해제합니다.
10. TypeScript → Utility types에서 JS 전용 버튼이 비활성화되고 TS 코드만 복사되는지 확인합니다.
11. CSS 스택에서 Flexbox 예제를 열고 CSS 탭·하이라이팅·복사 코드가 일치하는지 확인합니다.
12. CSS 탭 하나만 제공될 때 Tab이 언어 전환에 가로채이지 않고 기본 포커스 이동을 하는지 확인합니다.

## 복사

- Chrome, Firefox, Safari에서 버튼·Enter 복사 후 내용을 직접 붙여넣어 비교합니다.
- iOS Safari와 Android Chrome에서는 터치로 복사하고 붙여넣습니다.
- 실패 시 성공 토스트가 아닌 오류 안내가 표시되어야 합니다.
- 복사 fallback 뒤 포커스와 입력 선택 영역이 유지되어야 합니다.
- 배포 환경은 HTTPS로 검사합니다. [Clipboard API의 보안 컨텍스트 조건](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/writeText)을 참고하세요.

| ---------- | ------------------------------------------ |
| 1440 × 900 | 3단 레이아웃, 페이지 전체 스크롤 없음      |
| 1024 × 768 | 3단 레이아웃, 패널 내부 스크롤             |
| 768 × 1024 | Drawer 메뉴, 목록/상세 단일 화면           |

| 320 × 568  | 버튼·언어 탭·메뉴가 잘리지 않음            |

- 모바일에서 항목 클릭 → 상세 → 목록 버튼으로 복귀합니다.
- Drawer의 닫기·Escape·포커스 복귀를 확인합니다.
- 긴 제목, 검색 결과 없음, 긴 코드, 펼친 Gotcha에서도 페이지 폭이 넘치지 않아야 합니다.
- 코드 복사에 줄 번호나 파일명이 포함되면 안 됩니다.
- 브라우저 확대 200%와 OS의 동작 줄이기 설정을 확인합니다.

실행 결과와 발견된 문제를 확인한 뒤 checklist.md의 수동 QA 항목을 갱신합니다.
